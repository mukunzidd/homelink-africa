## Still needs a native reader

- **Notary.** Changed nothing, but the file uses two words: `sale.how.notaryTitle` / `sale.noFunds` say "wakili (huru) wa viapo" (commissioner for oaths), while `abroad.*` says "mthibitishaji". A Kenyan or Tanzanian lawyer should pick one.
- **Clock times in templated strings.** `messaging.readAt`, `workspace.today.eta`, `booking.review.startsAt`, `booking.people.fixedSlot`, `booking.record.slot`, `account.overview.viewingOn`, `booking.viewing.doneBody` put "saa" before a {time} value. If {time} renders as 24h (14:30), a Swahili reader may count it on the Swahili clock. Fixed the hard-coded cases; these depend on how {time} is formatted.
- **Saved = "Vipendwa".** I moved the saved list to "Vipendwa" because "hifadhi" also means book. The save buttons themselves (`listing.save`, `detail.save`, `saved.save`, `saved.saveNamed`) still say "Hifadhi". Check whether that still reads as "book" next to the heart.
- **Inventory = "Huduma zako".** I replaced "Bidhaa" (goods). "Huduma" is also used for amenities in the editor tab and the smart-search relax chip.
- **Online check-in = "Jisajili mtandaoni".** Picked to avoid "Ingia" (sign in). Check that hotel-style "kujisajili" is what readers expect.
- `workspace.calendar.earlier` "Mapema" (early) for a pager button meaning "earlier dates". Possibly "Nyuma".
- `list.medianLabel` and `list.rentBarsCaption` say "Wastani" (average) for median.
- `reviews.new` "maoni moja" for one review. Spoken usage, but grammatically odd.
- `workspace.work.kind.midStay` / `extras.midStayClean.name` "Usafi katikati ya kukaa": understandable, slightly literal.
- `amenities.security` "Ulinzi eneo hili": understandable, slightly literal.
- `sale.kind.townhouse` "Nyumba ya safu": not sure it is current East African usage.
- "Pesa yako" vs "pesa zako" are both in the file. Both are normal in East Africa, so I only fixed strings that mixed them inside one card.
